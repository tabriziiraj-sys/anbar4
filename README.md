# سیستم مدیریت انبار

یک سیستم مدیریت موجودی وب‌محور کامل با رابط فارسی و راست‌به‌چپ.

## ویژگی‌ها

- ✅ مدیریت محصولات و دسته‌بندی‌ها
- ✅ ثبت ورود و خروج کالا
- ✅ پیگیری تراکنش‌ها و سابقه کامل
- ✅ هشدار موجودی کم
- ✅ گزارش‌گیری و خروجی CSV
- ✅ پایگاه داده SQLite (ذخیره در مرورگر)
- ✅ پشتیبانی از حالت تاریک/روشن
- ✅ طراحی واکنش‌گرا برای موبایل و دسکتاپ
- ✅ خروجی و پشتیبان‌گیری از دیتابیس
- ✅ نمایش وضعیت اتصال دیتابیس

## پیش‌نیازها

- **Node.js** نسخه 18 یا بالاتر ([دانلود](https://nodejs.org))
- مرورگر مدرن (Chrome, Firefox, Edge, Safari)

## نصب و اجرا

### روش سریع (ویندوز)

1. روی فایل `install.bat` دابل‌کلیک کنید تا وابستگی‌ها نصب شوند
2. روی فایل `start.bat` دابل‌کلیک کنید تا برنامه اجرا شود
3. مرورگر به طور خودکار باز می‌شود یا به آدرس `http://localhost:3000` بروید

### روش دستی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه Production
npm run build
```

## فایل‌های BAT

- **`install.bat`** - نصب تمام وابستگی‌های پروژه
- **`start.bat`** - اجرای سرور توسعه
- **`build.bat`** - ساخت نسخه Production

## مدیریت دیتابیس

### نمایش وضعیت اتصال

در گوشه بالای صفحه، یک نشانگر وضعیت دیتابیس وجود دارد:
- 🟢 **سبز**: اتصال برقرار است
- 🟡 **زرد**: در حال اتصال
- 🔴 **قرمز**: اتصال قطع یا خطا

با کلیک روی نشانگر، جزئیات بیشتر شامل حجم دیتابیس و زمان آخرین بررسی نمایش داده می‌شود.

### خروجی گرفتن از دیتابیس

از منوی **مدیریت دیتابیس** یا با کلیک روی نشانگر وضعیت:

1. **خروجی JSON**: فایل JSON شامل تمام داده‌ها به صورت ساختاریافته
2. **خروجی SQL**: فایل SQL شامل دستورات INSERT برای بازسازی دیتابیس

هر دو فایل با تاریخ روز نام‌گذاری می‌شوند.

### بازنشانی دیتابیس

در صفحه **مدیریت دیتابیس** می‌توانید دیتابیس را بازنشانی کنید:
- تمام داده‌های فعلی حذف می‌شوند
- دیتابیس با داده‌های نمونه پر می‌شود
- **هشدار**: این عملیات غیرقابل بازگشت است!

## پایگاه داده

این برنامه از **SQLite** در مرورگر استفاده می‌کند:
- داده‌ها در **IndexedDB** مرورگر ذخیره می‌شوند
- نیازی به سرور یا پایگاه داده خارجی نیست
- داده‌ها بین تب‌های مرورگر همگام می‌شوند
- با پاک کردن کش مرورگر، داده‌ها حذف می‌شوند

### داده‌های نمونه

پس از اولین اجرا، داده‌های نمونه شامل موارد زیر بارگذاری می‌شوند:
- ۴ دسته‌بندی
- ۸ محصول
- ۱۰ تراکنش نمونه

## عیب‌یابی

### برنامه اجرا نمی‌شود

1. مطمئن شوید Node.js نصب است: `node --version`
2. فایل `install.bat` را اجرا کنید
3. اگر مشکل حل نشد، پوشه `node_modules` را حذف و دوباره `npm install` را اجرا کنید

### داده‌ها نمایش داده نمی‌شوند

1. روی نشانگر وضعیت دیتابیس کلیک کنید
2. دکمه "بررسی مجدد اتصال" را بزنید
3. اگر خطا وجود دارد، پیام خطا را بررسی کنید
4. در صورت نیاز، از صفحه مدیریت دیتابیس، دیتابیس را بازنشانی کنید

### خروجی CSV کار نمی‌کند

- مطمئن شوید مرورگر اجازه دانلود فایل دارد
- پوشه دانلودها را بررسی کنید
- فایل باید با encoding UTF-8 باشد و متن فارسی را درست نمایش دهد
